## Goal

To gain theoretical knowledge and practical skills for working with Linux, 
including the console, running executable files, input/output operations, 
downloading files from the internet, working with archives, and searching 
for files and text.

## Topics Covered

The first stage covered the following sections: general course information, 
how to install Linux, getting started with Linux, terminal basics, running 
executable files, input/output, downloading files from the internet, working 
with archives, and searching for files and words in files.

## What I Did

Completed all test and interactive assignments across 9 sections. Key tasks included 
creating a text document in LibreOffice with a specific font and saving it as XML, 
finding the first author in VLC's About page, downloading and running an executable 
file from the terminal, redirecting error streams to files using pipes, downloading 
files with wget using various options, packing files into archives using tar and gzip, 
and searching through Shakespeare's works using grep to find all lines containing 
the word "love".

## Conclusion

As a result of completing the first stage, I gained practical experience with the 
Linux terminal, learned to run and manage executable files, work with input/output 
redirection, download files from the internet, handle archives, and search through 
files using find and grep.
