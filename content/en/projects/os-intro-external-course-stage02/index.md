## Goal

To gain theoretical knowledge and practical skills for working with Linux servers, 
including file exchange, launching applications, controlling running programs, 
working with multithreaded applications, and using the tmux terminal manager.

## Topics Covered

The second stage covered: working with a remote server, file exchange, launching 
applications, controlling running programs, multithreaded applications, the tmux 
terminal manager, and an extended guide to installing Linux.

## What I Did

Completed all test and interactive assignments across 6 sections. Key tasks included 
understanding how to safely transfer SSH keys, using scp to copy files to a remote 
server, working with FileZilla for file management, running programs on a server 
without a graphical interface, managing background processes using fg, bg, jobs, 
and kill commands, running the multithreaded bioinformatics tool bowtie2 and 
capturing its stderr output, and learning tmux commands for splitting windows, 
renaming tabs, and keeping sessions alive after disconnecting.

## Conclusion

As a result of completing the second stage, I gained practical experience with 
remote servers, learned to exchange files securely, manage running processes, 
work with multithreaded applications, and use tmux to maintain persistent 
terminal sessions on remote machines.
