## Цель работы

Получить теоретические знания и практические навыки работы с Linux:
освоить консоль, запуск исполняемых файлов, ввод/вывод, скачивание файлов
из интернета, работу с архивами, поиск файлов и слов в файлах.

## Темы этапа

Первый этап охватывал следующие разделы: общая информация о курсе, как
установить Linux, осваиваем Linux, основы терминала, запуск исполняемых
файлов, ввод/вывод, скачивание файлов из интернета, работа с архивами,
поиск файлов и слов в файлах.

## Что было сделано

Выполнены все тестовые и интерактивные задания по 9 разделам. Ключевые
задания включали: создание текстового документа в LibreOffice с заданным
шрифтом и сохранение в формате XML, нахождение первого автора в разделе
About программы VLC, скачивание и запуск исполняемого файла из терминала,
перенаправление потока ошибок в файлы с помощью конвейеров, скачивание
файлов с помощью wget с различными опциями, упаковка файлов в архивы с
помощью tar и gzip, поиск по произведениям Шекспира с помощью grep для
нахождения всех строк, содержащих слово «love».

## Выводы

В результате выполнения первого этапа получены практические навыки работы
с терминалом Linux, освоены запуск и управление исполняемыми файлами,
перенаправление ввода/вывода, скачивание файлов из интернета, работа с
архивами, поиск по файлам с помощью find и grep.
