## Цель работы

Получить теоретические знания и практические навыки работы с серверами Linux:
освоить обмен файлами, запуск приложений, контроль запускаемых программ,
взаимодействие с многопоточными приложениями и менеджер терминалов tmux.

## Темы этапа

Второй этап охватывал следующие разделы: знакомство с сервером, обмен
файлами, запуск приложений, контроль запускаемых программ, многопоточные
приложения, менеджер терминалов tmux, расширенное руководство по установке Linux.

## Что было сделано

Выполнены все тестовые и интерактивные задания по 6 разделам. Ключевые
задания включали: понимание правил безопасной передачи SSH-ключей, копирование
файлов на удалённый сервер с помощью scp, работа с FileZilla для управления
файлами, запуск программ на сервере без графического интерфейса, управление
фоновыми процессами с помощью команд fg, bg, jobs и kill, запуск многопоточного
биоинформатического инструмента bowtie2 с записью вывода stderr, освоение
команд tmux для разделения окон, переименования вкладок и сохранения сессий
после отключения.

## Выводы

В результате выполнения второго этапа получены практические навыки работы
с удалёнными серверами, освоены безопасный обмен файлами, управление
запущенными процессами, работа с многопоточными приложениями и использование
tmux для поддержания постоянных терминальных сессий на удалённых машинах.
