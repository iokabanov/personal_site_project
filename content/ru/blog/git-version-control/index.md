## Что такое система контроля версий?

Система контроля версий отслеживает изменения в файлах с течением времени.
Она позволяет возвращаться к предыдущим версиям, сравнивать изменения и
совместно работать над проектами без конфликтов.

## Что такое Git?

Git — распределённая система контроля версий, созданная Линусом Торвальдсом
в 2005 году для разработки ядра Linux. В отличие от централизованных систем,
каждый разработчик хранит полную копию репозитория на своём компьютере,
что позволяет работать полностью офлайн и синхронизировать изменения позже.

## Основные понятия

**Репозиторий** — папка проекта, отслеживаемая Git.

**Коммит** — сохранённый снимок изменений в проекте в определённый момент времени.

**Ветка** — независимая линия разработки, позволяющая работать над новыми
функциями, не затрагивая основной код.

**Слияние** — объединение изменений из одной ветки в другую.

**Удалённый репозиторий** — версия репозитория, размещённая на сервере,
например на GitHub или GitLab.

## Основные команды

```bash
git init              # инициализировать новый репозиторий
git clone <url>       # клонировать существующий репозиторий
git add .             # добавить изменения в индекс
git commit -m "msg"   # сохранить снимок изменений
git push              # отправить коммиты на удалённый сервер
git pull              # получить и применить изменения с сервера
git branch            # показать список веток
git merge <branch>    # слить ветку в текущую
git status            # показать состояние рабочей директории
git log               # показать историю коммитов
```

## Почему Git важен?

Git стал стандартом в разработке программного обеспечения. Он используется
практически в каждом современном проекте. Платформы GitHub и GitLab построены
на основе Git и позволяют миллионам разработчиков по всему миру совместно
работать над проектами.

Для студента-информатика освоить Git как можно раньше — одно из лучших вложений
времени. Этот инструмент будет сопровождать вас на протяжении всей карьеры.
