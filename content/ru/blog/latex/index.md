## Что такое язык разметки?

Язык разметки — это система аннотирования текста, позволяющая компьютеру
форматировать и отображать его определённым образом. В отличие от языков
программирования, языки разметки описывают структуру и представление
контента, а не логику. Примеры: HTML для веб-страниц и Markdown для документации.

## Что такое LaTeX?

LaTeX (произносится «ла-тех» или «лэй-тех») — высококачественная система
вёрстки, широко используемая в академической среде, науке и инженерии.
Она была создана Лесли Лэмпортом в 1980-х годах как расширение TeX,
разработанного Дональдом Кнутом.

В отличие от текстовых процессоров, LaTeX работает по принципу
«что видишь — то и имеешь в виду»: вы пишете простой текст с командами
разметки, а LaTeX сам занимается форматированием.

## Зачем использовать LaTeX?

LaTeX является стандартным инструментом для написания научных статей,
диссертаций и технических документов по ряду причин:

- **Красивая типографика**: LaTeX создаёт профессионально оформленные документы,
  превосходящие по качеству большинство текстовых процессоров.
- **Поддержка математики**: система без труда обрабатывает сложные математические
  формулы, поэтому LaTeX является стандартом в математике, физике и инженерии.
- **Согласованность**: форматирование применяется автоматически и единообразно
  по всему документу.
- **Библиография**: управление списком литературы и перекрёстными ссылками
  значительно проще, чем при ручном оформлении.

## Базовая структура документа LaTeX

```latex
\documentclass{article}

\title{Мой первый документ}
\author{Иван Кабанов}
\date{\today}

\begin{document}

\maketitle

\section{Введение}
Это мой первый документ в LaTeX.

\section{Пример математики}
Формула дискриминанта:
\[ x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a} \]

\end{document}
```

## Основные команды

| Команда | Назначение |
|---|---|
| `\section{}` | Заголовок раздела |
| `\textbf{}` | Жирный текст |
| `\textit{}` | Курсив |
| `\begin{itemize}` | Маркированный список |
| `\frac{}{}` | Дробь |
| `\sqrt{}` | Квадратный корень |

## С чего начать?

Самый простой способ начать работу с LaTeX без установки программ —
[Overleaf](https://www.overleaf.com), бесплатный онлайн-редактор LaTeX,
который компилирует документ прямо в браузере в режиме реального времени.
Он идеально подходит для написания отчётов, заданий и дипломных работ.

LaTeX поначалу требует привыкания, но освоив его, вы вряд ли захотите
возвращаться к обычному текстовому процессору для академических текстов!
